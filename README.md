## 阅读方式

1. **人物**：经历、角色、关键转折。
2. **公司**：业务、产品、规模、估值及未来方向，数字附时间和来源。
3. **学习与思考**：沿访谈主题梳理观点、上下文、短原文与分析。完整原文的阅读入口见各 PDF；这些文件是精选研究，不是全文转载。

胡渊鸣、杨硕、Amjad Masad 三篇已基于可获取的全文来源开展精选研究；翁家翌仍有全文覆盖缺口，Guillermo Rauch 的第三部分尚未完成。当前不将五篇统称为完成版。
